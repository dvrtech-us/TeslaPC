# rustls replaces http.sys binding

- Date: 2026-11-07
- Feature: https-bootstrap
- Related code: `teslapc/src/certs.rs`, `teslapc/src/decisions/renewal.rs`

## Context

The C# server imported a certificate into LocalMachine and bound it with netsh http.sys.

## Decisions

rustls terminates `8443`. DNS-01 still uses the Cloudflare token. Renewal at 30 days or fewer is `needs_renewal`. A local certificate covers the no-hostname case.

## Alternatives Considered

- Reuse an existing http.sys binding: rejected.

## Consequences

- Positive: Linux can serve HTTPS with the same code.
- Negative: a certificate that was only in the Windows store is not picked up.
