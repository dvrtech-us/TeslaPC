# File Browser and Playback

`/list.html` is generated by `render_guts`. Folders are emitted before files. A watched row shows the badge `Watched`. A missing or unreadable folder is HTTP 200 with the empty state (`doesn't exist` or the read error), not HTTP 500.

`resolve_browse` refuses a path that normalizes outside `TESLAPC_VIDEO_ROOT` (default `C:\video\` on Windows). Video extensions are `.mp4`, `.mkv`, `.avi`, `.mov`, `.m4v`, `.wmv`, `.flv`, `.webm`, `.mpg`, `.mpeg`, `.ts`, `.m2ts`.

Playback routes: `/media/play?path=`, `/media/pause`, `/media/resume`, `/media/seek?t=` (seconds), `/media/stop`, `/media/status`. Status JSON fields are `ffmpeg`, `playing`, `paused`, `position`, `duration`, `file` (file name).

ffmpeg args come from `ffmpeg_video_arg_list`: `-vf scale=-2:'min({maxH},ih)',fps=30` and `-c:v mjpeg -q:v 6`. Audio is resampled to the announced format. Playback resumes when the saved position is past 5 seconds and below 95% of duration. `TESLAPC_FFMPEG` overrides the executable.

If ffmpeg is missing, Windows `play.html` runs `windows_vlc_plan`: stop `vlc.exe`, wait `2000` ms, then `C:\Program Files\VideoLAN\VLC\vlc.exe` with ` -vvv "<file>" --fullscreen`. Linux `play.html` returns `linux_missing_ffmpeg_error` and does not launch another player. `/media/play` does not launch VLC.
